Subsea cable outages
There's no free, live API for subsea cable fault status — this isn't something a static page can reliably check, so rather than fake it, here are the real sources network engineers actually use:

TeleGeography Submarine Cable Map — reference map of global cable routes: submarinecablemap.com
Cloudflare Radar Outage Center — tracks significant internet disruptions, including some cable-related events: radar.cloudflare.com/outage-center
ISOC Pulse — internet resilience & shutdown tracking: pulse.internetsociety.org
